# ADR 0024 — AAA verification gates + asset/audio pipeline

Date: 2026-09-26

## Status

Accepted

## Context

Worldloop already ships a strong verification harness: `check_world.mjs`
(75/75 green) runs real systems against the real three package, plus a
dependency-free headless Chromium smoke (`node check_world.mjs --ci`) and the
pi-loop agent. But there are **no unit-test framework, no visual-regression,
no perf-regression, no GitHub Actions**, and **no asset or audio pipeline** —
everything is procedural geometry; nothing streams/preloads.

## Decision

- Verification: add a node unit-test runner seeded from `core/rng.js`
  (ADR 0022), headless visual-regression screenshots, and frame-budget
  perf-regression thresholds over `telemetry.js`. Wire all four into
  GitHub Actions CI/CD (`build → unit → smoke → visual → perf → deploy`).
- Assets: add `render/assets.js` (GLTF/GLB + KTX2/Basis + streaming +
  preload manifest) and an `assets/` directory; convert hero props (cranes,
  cars, EMS) to authored GLB + textures with LOD.
- Audio: add a WebAudio bus (master/music/sfx buses, pooling, mute/pause).

## Consequences

- AAA release gates become automated and reproducible.
- Authored assets replace some procedural builders (`car_models.js` etc.),
  enabling higher-fidelity art while keeping procedural fallbacks.
- Requires the bundled build (ADR 0021) and the seeded core (ADR 0022).
