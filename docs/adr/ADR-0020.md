# ADR 0020 — Night-time window illumination

Date: 2026-09-26

## Status

Accepted

## Context

The city had a fixed day/night cycle (a 10-minute day) and `weather.js`
already computed a `windowInt` factor and referenced `this.materials.window`,
but the world material cache never provided a `window` material and no
building geometry carried emissive window lights — a dangling reference that
silently no-op'd. At night the city stayed uniformly dark; only streetlights
and neon glowed. A "living skyline" needs buildings to come alive after dark.

## Decision

Add night-time window illumination driven by the existing day/night cycle:

- `world.js` introduces a shared `matWindow` — a transparent warm
  `MeshBasicMaterial` — and exposes it in the world material cache as
  `window`.
- A `addWindowLights` helper lays a deterministic grid of "lit window"
  panels on each building's road-facing facades. A window is lit when its
  position noise crosses a threshold (`SimplexNoise` over coordinates), so
  the same building always shows the same lit windows across reloads.
  Window panels are merged into a single InstancedMesh sharing `matWindow`.
- `weather.js` completes the previously-dangling reference: `updateTimeCycle`
  now modulates both the window material's color (dark `0x111111` → warm
  `0xffffaa`) AND opacity (`0.08` by day → `1.0` at night). Because the
  material is shared, weather lights every window in the city at once.
- Construction sites (partial buildings) are intentionally skipped — they
  are unfinished and should not appear occupied.

## Consequences

- Buildings visibly glow at night, giving the skyline a lived-in look that
  connects to the existing seasonal/day cycle and post-processing bloom.
- By day the window panels dim to near-invisible dark panels, so the effect
  is subtle and doesn't wash out daylight scenes.
- Determinism is preserved: lit-window patterns are stable per building, and
  the shared-material approach keeps the weather update O(1).
- Verified in `check_world.mjs`: the `window` material is present, window
  panels are merged as an InstancedMesh sharing `world.materials.window`,
  and weather lights windows at night / dims them by day.
