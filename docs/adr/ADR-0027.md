# ADR 0027 — Persisted settings: quality tiers, control remap, audio (AAA-07)

Date: 2026-09-26
Status: Accepted
Supersedes: hardcoded boot knobs scattered across `main.js`

## Context

AAA-05/AAA-06 introduced a deterministic App state machine and a logical input
layer (ActionMap). Before AAA-07, the boot path hardcoded the renderer
pixel-ratio cap, the chunk-streaming radius, and the input bindings directly in
`main.js` — no way for a player to tune quality, remap controls, or set audio
prefs, and nothing persisted between sessions. AAA-08 (save/continue) needs a
stable, round-trippable settings blob.

## Decision

Introduce `src/core/settings.js` — a single `Settings` object that owns:

- **Quality tiers** (`low`/`medium`/`high`/`ultra`). Each tier maps to a
  `QUALITY_PARAMS` entry: a pixel-ratio cap (applied to the renderer at boot),
  a draw-distance scale (scales the chunk-streaming radius), and a `postFx`
  flag consumed later by the post-FX tier pass (AAA-16).
- **Control remap** — persists the logical `ActionMap` bindings
  (`{ action: [codes...] }`). At boot `main.js` builds
  `new ActionMap(settings.bindings)` so a player's remap survives reload.
- **Audio prefs** (`muted`, `master`, `music`, `sfx`) — a data-only preference
  blob the future audio bus (AAA-13) reads; no audio hardware is touched yet.

Persistence is JSON under one storage key (`worldloop.settings`) via a
Node-safe shim (`createStorage()`): real `localStorage` when present, otherwise
an in-memory Map so the verification harness can round-trip save/load without a
browser. `Settings` deep-merges persisted values over frozen defaults, ignores
corrupt JSON, and validates unknown quality tiers back to `high`. It exposes a
machine-readable `snapshot()` for telemetry / AAA-08 save blobs.

`main.js` wires it as the single source of truth: it caps the renderer
pixel-ratio, scales the chunk-manager `renderDistance`, and rehydrates the
`InputManager` logical map from `settings.bindings`. `window.settings` is
exposed for the UI/settings menu.

## Consequences

- Quality, remap, and audio are tunable and persist across reloads.
- `main.js` no longer hardcodes pixel-ratio / render-distance / bindings.
- AAA-08 save/continue can embed `settings.snapshot()`.
- AAA-13 audio bus reads `settings.audio`; AAA-16 post-FX tiers read
  `QUALITY_PARAMS[tier].postFx`.
- Node harness verifies the whole round-trip with a memory storage shim.
