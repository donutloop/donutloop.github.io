# ADR 0022 — Seeded deterministic RNG + fixed-timestep core

Date: 2026-09-26

## Status

Accepted

## Implementation status

- **AAA-03 (seeded deterministic RNG) ✅ DONE (Round 3)** — added `src/core/rng.js`
  (xorshift32 PRNG with a shared global instance, `setSeed`/`getSeed`/`DEFAULT_SEED`),
  seeded the `noise.js` simplex permutation from it (lazy build + `resetNoise()`
  test hook), and `main.js` calls `setSeed(DEFAULT_SEED)` before building the
  world. `road_graph.js` already had no `Math.random`; its layout is deterministic
  and now shares the same seeded RNG path for any future stochastic steps.
  `check_world.mjs` gains seeded-RNG checks (same-seed determinism, seed-dependent
  noise, `getSeed` reflection). Seed is exposed via `DEFAULT_SEED` for a later
  settings/AAA-07 pass.
- **AAA-04 (fixed-timestep core/time.js) ⏳ NEXT** — see roadmap.

## Context

`src/noise.js` seeds its 256-entry `SimplexNoise` permutation from
`Math.random()` at module load, and `road_graph.js` chunk generation depends
on it. This is deterministic *within* a session only — **not across** runs,
which blocks reproducible E2E/visual-regression and save/replay (AAA-08).
`src/main.js` computes `delta` from `performance.now()` and calls
`chunkManager.update()` twice per frame; `scene.js` `animate(cb)` invokes `cb`
synchronously. There is no frame-budget enforcement and no pause hook.

## Decision

- Introduce a seeded PRNG (e.g. xorshift) as `core/rng.js`; seed the noise
  permutation and road graph from it. Expose `seed` through config and save.
- Introduce a fixed-timestep `core/time.js`: accumulator, `update(dt)` /
  `render()` split, frame-budget clamp, pause/resume. `main.js` calls exactly
  one `update()` per frame.

## Consequences

- Reproducible worlds for a given seed (visual-regression, replay, CI).
- Stable simulation independent of display refresh rate.
- Requires touching `noise.js`, `road_graph.js`, `chunk_manager.js`,
  `scene.js`, `main.js`; `check_world.mjs` fixtures gain seeded runs.
