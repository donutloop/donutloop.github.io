# ADR 0022 — Seeded deterministic RNG + fixed-timestep core

Date: 2026-09-26

## Status

Accepted

## Context

The simulation currently uses a single global `Math.random()` stream plus a
per-frame `dt` from the rAF loop, so two identical runs can diverge and physics
depends on the display refresh rate. This blocks reproducible E2E/visual
regression and makes replays unstable.

## Decision

- Introduce `src/core/rng.js` as a seeded xorshift PRNG and replace
  `Math.random()` in world/road-graph generation with it.
- Introduce `src/core/time.js` `FixedTimestep` (classic accumulator) so sim
  systems advance at a fixed dt regardless of display refresh, with a
  frame-budget clamp and pause/resume.

## Consequences

- Reproducible worlds for a given seed (deterministic road graph / noise).
- Deterministic physics/AI independent of monitor refresh rate.
- Requires seeding `core/rng.js` from main.js, and check_world.mjs to assert
  determinism plus the fixed-timestep clamp/pause behavior.

## Implementation status

- **AAA-03 (seeded deterministic RNG) ✅ DONE (Round 3)** — added `src/core/rng.js`
  `RNG` (xorshift32, 32-bit state, `float()/int(n)/range(min,max)`), seeded in
  main.js, wired into world/road-graph generation, exposed on
  `window.__worldloop.rng`; check_world.mjs asserts same-seed determinism and
  cross-seed divergence.

- **AAA-04 (fixed-timestep core) ✅ DONE (Round 4)** — added `src/core/time.js`
  `FixedTimestep`: classic accumulator advances sim systems at a fixed 30Hz
  (`FIXED_DT = 1/30`, `MAX_STEPS_PER_FRAME = 4` budget clamp), then renders once
  per frame with the leftover accumulator as interpolation alpha.
  `pause()/resume()/toggle()` freeze the accumulator (P key in main.js);
  `telemetry.recordClock(snapshot)` exposes steps/dropped/paused. Wiring:
  main.js drives `simClock.advance(dt, onUpdate, onRender)` with an
  update/render split; check_world.mjs asserts determinism, the budget clamp,
  pause/resume, and the wiring.
