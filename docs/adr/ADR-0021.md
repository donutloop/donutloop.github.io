# ADR 0021 — Bundled local build (drop CDN importmap)

Date: 2026-09-26

## Status

Accepted

## Context

`index.html` loads `three@0.160.0` from the unpkg CDN via an inline
`importmap` (`"three"` / `"three/addons/"`). This is a runtime network
dependency: no version pinning/integrity, no tree-shaking, no code-splitting,
no offline story, and it blocks authored-asset pipelines (GLTF/KTX2) and
deterministic CI. `package.json` currently has only `three` as a dependency
and no build step.

## Decision

Adopt a local bundler (Vite or esbuild) with `three` as a pinned dev-dep.
`index.html` loads a bundled entry (`src/main.js`) instead of a CDN importmap.
Add `build`, `dev`, `preview`, `test`, `typecheck` scripts. Keep the runtime
entry contract identical so `check_world.mjs` (which imports the real three
package from `node_modules`) keeps working unchanged.

## Consequences

- Deterministic, offline-capable, tree-shaken production bundle.
- Enables asset pipeline (ADR 0024) and CI/CD (AAA-20).
- New dev loop (`npm run dev`) replaces the static-page CDN flow.
- Requires updating `index.html`, `package.json`, and the headless CI driver
  (`tools/ci/headless_cdp.mjs`) to serve the built artifact.
