# ADR 0029 — Spatial broadphase (uniform grid) for collision colliders (AAA-09)

Date: 2026-09-26
Status: Accepted
Supersedes: per-frame `getColliders()` full concatenation in `chunk_manager.js`
Related: ADR 0018 (CI smoke), ADR 0022 (LOD)

## Context

The player collision path rebuilt the FULL collider set every fixed step:
`getColliders()` concatenated every streamed chunk's `Box3` colliders (plus all
parking/traffic colliders) into a fresh array per frame. With a 3-chunk render
radius (7x7 = 49 chunks) that is a large per-frame allocation of mostly-far-away
colliders the player can never touch. AAA-09 replaces this with a uniform-grid
spatial broadphase so the hot path visits only nearby cells.

## Decision

1. **`SpatialGrid`** — a uniform grid in `chunk_manager.js`. Cells align to the
   chunk grid (`chunkSize`); each static collider is bucketed by its AABB center
   cell. `query(x,z,r)` visits only the cells overlapping a radius box around a
   point.
2. **Static colliders are bucketed once on stream** — inserted in `loadChunk`,
   removed in `unloadChunk`. Never rebuilt per frame. LOD rebuilds (re-insert on
   the new chunk) are handled naturally because each chunk owns its `colliders`.
3. **`getCollidersNear(x, z, radius)`** — the new per-frame hot path. It returns
   the static grid subset (nearby cells) plus parking/traffic colliders
   distance-culled within `radius`. `getColliders()` is retained for
   compatibility/full-set callers.
4. **`main.js`** assigns `player.colliders` from `getCollidersNear(...)` each sim
   step, replacing the per-frame full `getColliders()` concat.

## Consequences

- Per-frame collision work is proportional to the query radius, not the render
  distance — the 7x7 chunk concat is replaced by a ~1-3x3 cell visit.
- Static colliders stay in the grid until their chunk unloads or is LOD-rebuilt,
  so collision is streamed-in with the world and needs no per-frame bookkeeping.
- Dynamic colliders (parking/traffic) are still gathered per frame but
  distance-culled, so their cost stays local.
- `getColliders()` remains available for callers that genuinely need the full
  set; only the hot path uses the broadphase.
